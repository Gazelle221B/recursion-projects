FAQ

無料プランは何ができますか？

プロジェクトを3つまで作成でき、基本的なタスク管理機能と基本サポートを利用できます。ストレージは1GBまでです。

解約はどうすればいいですか？

設定画面のプラン管理からいつでも解約できます。解約後も契約期間の終了までは有料機能を利用できます。

チームに人数制限はありますか？

Proプランでは人数制限なくチームメンバーを招待できます。Freeプランでは個人利用を想定しています。

タスクのエクスポートはできますか？

はい。タスク一覧はCSV形式でエクスポートでき、他のツールへの移行やバックアップに使えます。
